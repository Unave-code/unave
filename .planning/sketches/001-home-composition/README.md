# Sketch 001: Home composition

## Design Question

How should the home page be composed so it feels like a food brand, not a template, while keeping the current beats and chrome?

## How to View

Open `.planning/sketches/001-home-composition/index.html` in a browser. Switch A / B / C in the top bar.

## Variants

- **A: Editorial table** — The photograph is the page. Type sits in the plate. The shelf is a two-column magazine spread. Other beats become captions, not cards.
- **B: Quiet catalog** — Commerce first. A shorter, still-feeling hero, then large plates. Story, difference and FAQ are compressed into thin bands so the food stays the subject.
- **C: Kitchen film** — Home as a vertical film. Who-it-is-for becomes four full-bleed chapters. The shelf is a horizontal plate runway. Difference is pull-quotes, not a bento.

## What to Look For

- Does the carousel still feel calm, or does it fight the photograph?
- Does the shelf make you want the food before you read a sentence?
- Which restaging of “who / story / how / different / FAQ” still earns its keep?
- Does the announcement + green header + WhatsApp bubble survive a premium pass, or does it still feel like kit?

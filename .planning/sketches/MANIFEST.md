# Sketch Manifest

## Design Direction

A calmer, more premium UNAVE public site that still reads as the same kitchen: forest green and gold, Lora with Plus Jakarta Sans, existing photographs only. Home is the first cut. The job of the page is to make a stranger want the food, then browse. Keep the CMS carousel and the current chrome (announcement, transparent-then-green header, WhatsApp bubble), but restage every beat so it no longer feels like a website kit. Beats that stay: who it is for, kitchen story, product shelf, how it works, what makes us different, FAQ.

## Reference Points

No external brand references named. Direction is internal: editorial food brand, photo-first, honest copy, not a restaurant theme.
